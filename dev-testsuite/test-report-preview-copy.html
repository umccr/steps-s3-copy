How are costs calculated?
  • S3 cross-region read/write: ~$0.14 per GB transferred between AWS regions (S3 in-region copies are free)
  • Cold storage retrieval (varies by thaw speed and storage class):
    • Glacier: Bulk $0.0034/GB, Standard $0.013/GB, Expedited $0.27/GB
    • Deep Archive: Bulk $0.011/GB, Standard $0.03/GB
    • Intelligent Tiering Archive Access: Bulk $0.0034/GB, Standard $0.013/GB, Expedited $0.27/GB

  • Compute:
    Lambda: $0.00001964 per GB-second × memory × duration, plus $2.7e-7 per invocation
    Fargate: $0.071 per vCPU-hour, $0.008 per GB-hour (min 60s)
